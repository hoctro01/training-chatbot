import argparse
from sr_report_bot.websocket_listener import start_listener

def main():
    # 1. Tạo cờ lệnh để chọn cách khởi động
    parser = argparse.ArgumentParser()
    parser.add_argument("--serve", action="store_true")
    args = parser.parse_args()

    # 2. Xử lý khởi động
    if args.serve:
        print("🤖 Đang khởi động Bot...")
        start_listener() # Bật Ăng-ten 24/7!

if __name__ == "__main__":
    main()

🎬 Deploy Production - Windows (Kể cả Win 10/11)

  • Công cụ: NSSM (Non-Sucking Service Manager) - Giúp bot chạy ngầm vĩnh viễn, không bị của sổ đen CMD cản trở.
  • Quy trình:
    1. Tải nssm.exe, mở CMD quyền Admin: nssm install SR_Report_Bot
    2. Bảng hiện ra:
      • Path: C:\sr_report_bot\.venv\Scripts\python.exe
      • Arguments: src\sr_report_bot\main.py --serve
    3. Bấm Install service & Mở thẻ Services của Windows để Start.

🎬 Deploy Production - Ubuntu (Linux)

  1. Copy toàn bộ code vào /opt/sr_report_bot và chuẩn bị thư viện y như lúc code.
  2. Tạo file: sudo nano /etc/systemd/system/sr_report_bot.service

[Unit]
Description=SR Report Bot Service
[Service]
WorkingDirectory=/opt/sr_report_bot
ExecStart=/opt/sr_report_bot/.venv/bin/python src/sr_report_bot/main.py --serve
Restart=always
[Install]
WantedBy=multi-user.target
  1. Lệnh kích hoạt phép thuật:
    • sudo systemctl daemon-reload
    • sudo systemctl enable --now sr_report_bot (Chạy & Tự khởi động)
