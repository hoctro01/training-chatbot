🔌 Bước 4: WebSocket Chatbot


# websocket_listener.py — Lắng nghe message real-time

import websockets, asyncio, json

async def listen(ws_url, bot_token):
    async with websockets.connect(ws_url) as ws:
        # 1) Authenticate
        await ws.send(json.dumps({
            "action": "authentication_challenge",
            "data": {"token": bot_token}
        }))

        # 2) Listen loop
        async for msg in ws:
            event = json.loads(msg)
            if event["event"] == "posted":
                post = json.loads(event["data"]["post"])
                user_msg = post["message"]     # Nội dung user gửi
                channel = post["channel_id"]   # Channel để reply

                # 3) Routing → xử lý → reply
                response = route_message(user_msg, channel)
                send_post_to_channel(..., message=response)

🔀 Message Router — Phân luồng tin nhắn


# message_router.py

def route_message(text: str, channel_id: str) -> str:
    """Parse message → route tới handler phù hợp."""

    if text.startswith("/help"):
        return handle_help()

    elif text.startswith("/report"):
        return handle_report()        # → Bảng KPI đầy đủ

    elif text.startswith("/check"):
        department = text.replace("/check", "").strip()
        return handle_check(department)  # → KPI 1 phòng

    elif text.startswith("/overdue"):
        return handle_overdue()        # → Danh sách quá hạn

    else:
        # Không phải lệnh → hỏi LLM
        return handle_question(text, channel_id)
💡 Mở rộng: Thêm command mới = thêm 1 hàm handler + 1 dòng if/elif

🧠 Bước 5: Tích hợp AI (LLM)

Flow


User: "Phòng nào nhiều SR quá hạn?"
         │
         ▼
┌─────────────────────┐
│ 1. Query data       │
│    → load report    │
│    → get stats      │
├─────────────────────┤
│ 2. Build prompt     │
│    system + data    │
│    + user question  │
├─────────────────────┤
│ 3. Call LLM API     │

├─────────────────────┤
│ 4. Return response  │

System Prompt quan trọng

  • Định nghĩa vai trò AI
  • Quy tắc: CHỈ dùng data được cung cấp
  • Format output (Markdown, emoji)
  • Giới hạn độ dài

⚠️ Chú ý

  • LLM có thể bịa số liệu → phải grounding bằng data thật
  • Retry + backoff khi API lỗi
  • Timeout 60s, fallback message

📝 Prompt Engineering cho Bot


SYSTEM_PROMPT = """
Bạn là trợ lý AI của phòng [TÊN PHÒNG], chuyên trả lời câu hỏi
về [NGHIỆP VỤ].

Quy tắc bắt buộc:
- CHỈ dùng dữ liệu được cung cấp. KHÔNG bịa thêm số.
- Nếu thiếu dữ liệu → nói rõ "chưa đủ dữ liệu".
- Tiếng Việt, ngắn gọn, chuyên nghiệp.
- Format Markdown, dùng emoji phù hợp.
- Giới hạn 5-10 dòng.
"""

def build_messages(question, data_context):
    return [
        {"role": "system", "content": SYSTEM_PROMPT},
        {"role": "user",   "content": f"Dữ liệu:\n{data_context}"},
        {"role": "assistant", "content": "Đã nhận dữ liệu."},
        {"role": "user",   "content": question},
    ]

🧪 Viết Test


# tests/test_your_bot.py
import pytest
from your_bot.job import calculate_kpi

class TestCalculateKPI:
    def test_all_on_time(self):
        """100% đúng hạn → Đạt"""
        result = calculate_kpi(on_time=10, total=10, target=0.95)
        assert result["rating"] == "Đạt"

    def test_below_target(self):
        """Dưới target → Không đạt"""
        result = calculate_kpi(on_time=5, total=10, target=0.95)
        assert result["rating"] == "Không đạt"

    def test_zero_total(self):
        """Tổng = 0 → không crash"""
        result = calculate_kpi(on_time=0, total=0, target=0.95)
        assert result["rate"] == 0
Chạy test: PYTHONPATH=src python -m pytest tests/ -v

[Unit]
Description=My Chatbot
After=network.target

[Service]
Type=simple
WorkingDirectory=/path/to/bot
Environment=PYTHONPATH=src
ExecStart=/path/.venv/bin/python \
  -m automation_bot.main --serve
Restart=always

[Install]
WantedBy=multi-user.target

🔬 Lab: Tạo Bot Giám sát Sự cố

Đề bài

Tạo bot báo cáo sự cố mạng hằng ngày. Dữ liệu từ file Excel.

Yêu cầu

  • Đọc file incidents.xlsx
  • Tính: tổng sự cố, đã xử lý, đang mở
  • Gửi báo cáo lên NetChat
  • Command /incidents
  • AI trả lời: "Sự cố nào nghiêm trọng nhất?"

Gợi ý

  1. Copy chatbot_ksvhkt
  2. Sửa process_data/ → đọc Excel
  3. Sửa job.py → format message
  4. Thêm /incidents vào router
  5. Viết prompt cho sự cố mạng

💎 Best Practices

✅ NÊN

  • Dùng logging thay print()
  • Có --dry-run cho mọi bot
  • Viết test cho business logic
  • Config tập trung qua .env
  • LLM prompt: grounding bằng data thật
  • Retry + backoff cho API calls
  • Auto-reconnect WebSocket

❌ KHÔNG NÊN

  • Hardcode credentials trong code
  • Commit .env lên Git
  • Hardcode đường dẫn Windows
  • Bỏ qua error handling
  • Dùng except: pass
  • Để LLM tự bịa số liệu
  • Deploy mà không test trước
